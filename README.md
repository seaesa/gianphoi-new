# gianphoi-new

Clone website project with AI skills.

## Skills
- `firecrawl-website-design-clone` — Extract design system via Firecrawl (`DESIGN.md`)
- `clone-website` — Pixel-perfect website cloning

## Usage
```bash
# Install skills
npx skills add https://github.com/firecrawl/firecrawl-workflows --skill firecrawl-website-design-clone
npx skills add https://github.com/julianromli/ai-skills --skill clone-website
```
